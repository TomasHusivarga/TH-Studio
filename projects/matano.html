Matano

Web pre spoločné spievanie dospelých. Návštevník sa rýchlo dozvie, ako stretnutia fungujú, aké skupiny sú v ponuke a ako sa prihlásiť.

Typ projektuPrezentačný web / registrácie
StackWordPress, WooCommerce, responzívny dizajn
Otvoriť live web

Východiská

Matano ponúka dospelým spoločné spievanie bez nároku na spevácke skúsenosti. Web mal tento koncept vysvetliť jednoducho a pomôcť návštevníkom vybrať si skupinu a nájsť informácie o stretnutiach.

Rozsah práce

  • WordPress homepage s jasným predstavením programu a jeho priebehu.
  • Prehľad skupín, cyklov a termínov s nadväzujúcou cestou k prihláseniu.
  • Responzívny layout a obsahové sekcie pre lektorov, časté otázky a kontakt.
  • Prepojenie informácií o skupine s registračným procesom.

Dizajnový smer

Jemná farebná paleta, výrazná typografia a vlastná ilustrácia dávajú webu osobitý charakter. Otvorený layout necháva vyniknúť samotnému programu a drží informácie o skupinách prehľadné.

Výsledok

Web spája predstavenie Matana, výber skupín a informácie o stretnutiach s jasným postupom prihlásenia. Obsah je rozdelený tak, aby sa návštevník vedel rozhodnúť bez hľadania podstatných informácií naprieč stránkou.
